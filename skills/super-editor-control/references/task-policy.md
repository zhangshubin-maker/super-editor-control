# 任务规模、持久化与验证策略

本文件是所有 Super Editor 技能的公共策略唯一来源。出现冲突时，按以下优先级执行：

1. 用户当前明确要求；
2. 本策略；
3. 各领域技能的具体操作步骤；
4. 示例。

运行时 MCP Schema 和工具返回错误高于文档中的旧示例。所有调用优先使用 `editor_*` MCP 工具；
只有没有专用工具时才使用 `editor_rpc_call`。浏览器控制只用于打开页面、只读探测或辅助截图，
不通过页面 evaluate、鼠标或键盘修改画布。

## 1. 先判断任务规模

任务规模主要由**预期写入影响面**决定，不由读取工具的 `scope` 或只读参考页数量决定。只修改当前页时，
可以为复用成熟风格进行少量跨页只读：先读 slide list 或 book summary，再只读 1–3 个代表页；这仍是
`current` 写入，不因此升级为整书 checkpoint、逐页写入或 book 审计。

| 规模 | 典型请求 | 默认读取 | 写后验证 |
|---|---|---|---|
| `micro` | 改一个错字、一个文本 target、一个元素几何、一个数字模块 | 只读目标及其必要外层；目标不明确才搜索当前页 | 复读同一目标；画布 dirty 时保存当前页 |
| `current` | 制作或重排一个区块、一个当前目录 | 读取目标区块及相关元素；需要复用风格时可按上限只读代表页 | 核对受影响区块、相关审计、保存当前页 |
| `book` | 多目录写入、整书交付、全书一致性修改/审计或需要跨目录内容结论 | 分页读取 book summary；只对命中页 deep 读取 | 每页 current 验证并保存；交付时才分页 book 审计 |

禁止仅因工具可用而升级范围。micro 不读取整页备份、不搜模板、不做全局审计；current 可做有界的
代表页风格只读，但不逐页深读全书、不修改参考页、不做整书审计；book 必须逐页执行，不能把一次
整书扫描当成逐页保存。

## 2. 按风险使用 checkpoint

`editor_checkpoint` 是当前会话、当前页的整页深拷贝，刷新或切换上下文后可能失效。

- **低风险**：单一文本局部编辑、单元素样式或几何、可直接复读的资源替换——默认不打 checkpoint。
- **中风险**：多元素重排、组内联动、表格/思维导图结构调整、插入或批量修改区块——写前打一次。
- **高风险**：删除/替换区块、清空或重建当前页、大批量结构改写——确认目标和影响范围后打 checkpoint。
- **受控完整 JSON 替换**：即使 ID 全部保持不变，也属于中风险；写前至少完成工具内置 dry-run 和
  `expectedHash` 校验，组树或整区块替换再按影响面建立 checkpoint。数字模块挂钩的 element id 变化必须
  零写入拒绝，不能依靠写后补绑修复。
- **立即持久化操作**：checkpoint 不能回退。写前读取现状并保留恢复所需标识；破坏性操作须有用户明确意图。

不要把“任务开始”当成无条件 checkpoint 触发器，也不要在每个小步骤重复创建整页快照。
文件系统可用且任务确实需要跨会话恢复时，才可额外导出页面 JSON；磁盘备份不是 micro 默认步骤。

## 3. 保存与切页

- 画布、区块、元素、文本和应用到当前页的区块/组件/图片先写工作副本；dirty 时使用
  `editor_save_verified({ scope: 'current', expectedSlideId, verify: true })`。
- `expectedContentHash` 只能使用写后、保存前取得的**页级** hash；不能传文本 target hash 或审计 `sourceHash`。
- `editor_save_verified(scope=book)` 仍只保存当前 dirty 页，然后附加整书摘要校验；它不会逐页保存整书。
- book 任务每完成一页都调用 current 保存，不把所有 dirty 风险留到最后。
- 切页前若当前页 dirty，默认调用
  `editor_select_slide({ slideId, saveBeforeSwitch: true })`；只有用户明确要求放弃改动时才传
  `discardChanges: true`。不要同时传两个选项，也不要假设切页会自动保存。
- 普通任务不使用 `editor_save` + 页面刷新作为验证流程；使用 `editor_save_verified` 的服务端回读结果。

## 4. 持久化与回滚域

| 操作域 | 持久化 | checkpoint/rollback |
|---|---|---|
| 当前页区块、元素、文本；应用区块模板、组件、图片 | 当前页 dirty 后显式保存 | 可回退当前页 |
| 目录新增、删除、移动、重命名、复制；应用 `kind=chapter` 样章 | 后端立即写入 | 不可回退 |
| 页面级画布类型/宽度切换 | 目录信息立即写入；全部区块写工作副本后显式保存 | 只能回退区块工作副本，不能回退目录信息 |
| 大纲节点、关联和锚点 | 后端立即写入 | 不可回退 |
| 目录题目关系、题目讲解记录 | 后端立即写入 | 不可回退 |
| 数字模块创建、修改、删除、复制 | 后端立即写入 | 不可回退 |
| 书本创建及书本跳转 | 创建立即写入；跳转改变上下文 | 不可回退 |
| 文件上传 | 生成独立资源；是否被页面引用另行决定 | 不能用页面 rollback 删除上传资源 |

复合任务中必须分别报告各域结果。页面 rollback 成功不代表目录、大纲、题目或数字模块已恢复。

若业务所需编辑能力没有对应的 typed 原子工具，应在真实 Bridge 与 MCP 插件中补齐并加入契约测试；
不要把浏览器点击、页面 evaluate 或长期 `editor_rpc_call` 绕路固化进业务 Skill。

## 5. batch 不是事务

`editor_batch` 只减少往返，步骤仍按顺序执行：

- 前一步成功后，后一步失败不会自动撤销前一步；`stopOnError` 只控制是否继续。
- batch 中的 checkpoint 只能保护当前页工作副本，不能保护立即持久化域。
- 仅合并同一页、同一意图、可顺序验证的步骤；不要把跨页或多个持久化域包装成“原子操作”。
- `OUTCOME_UNKNOWN` 时禁止直接重放写操作，先复读目标状态再决定。

## 6. 最小充分验证

- `micro`：复读同一 target；仅当内容影响尺寸或视觉时检查外层布局/截图。
- `current`：复读返回标识和元素映射，检查受影响区块的结构、文本适配和截图，再运行相关 checks；
  若跨区块视觉关系本身就是验收目标，必须增加 `editor_screenshot({ fullPage: true })`，即使区块高度和
  页面流向没有变化。
- `book`：逐页执行 current 验证；整书交付才做分页 book 审计与代表性跨页风格核对。

静态审计不能证明教学正确、元素无遮挡、媒体可播放或学生端互动可用。需要时结合
`editor_get_canvas_tree`、文本布局检查、区块截图和学生端预览；明确报告尚未自动验证的部分。
