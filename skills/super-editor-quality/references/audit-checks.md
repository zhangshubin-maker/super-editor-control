# 课件质量检查项

## structure

- 目录名称缺失、目录没有区块、区块名称缺失。
- 元素 ID 缺失或重复。

不承诺检查组引用、大纲、锚点、目录跳转、题目或数字模块引用是否真实存在；这些由对应状态/大纲/题目/数字模块工具核对。

## text

- 文本类元素为空。
- 文本包含 Bridge 已知的默认占位词。

不承诺判断语义残缺、标题层级、字体/字号一致性、术语一致性，或公式、图片题干、复杂富文本 embed 的往返正确性。明确术语用文本/整书内容搜索；嵌套富文本用统一 target 读取并结合预览核对。

## resources

- Bridge 识别的媒体元素缺少资源地址。

不承诺验证资源 URL 可访问、题目 GUID 存在、答案/解析正确、AI 讲解记录存在、数字模块资源有效或目录跳转可达；有这些对象时加载对应专用技能读取。

## layout

- 坐标或尺寸不是有限数值。
- 顶层元素超出区块边界。

Bridge 静态审计不检测元素互相重叠、视觉遮挡、真实文本裁切、跨区块呈现或同类页面风格一致性。结合 `editor_get_canvas_tree`/页面结构、文本布局检查、区块截图或学生端预览验证；表格和思维导图还要检查真实编辑容器。

## 严重级别

- `error`：会导致内容缺失、无法保存、资源不可用或结构损坏，交付前必须处理。
- `warning`：可能影响阅读、教学完整性或一致性，需要人工或 AI 复核。
- `info`：优化建议，不阻塞保存与交付。

每条报告携带稳定问题 ID 和内容 `sourceHash`。修复前若 hash 已变化，应重新审计。

这些严重级别只描述 Bridge 已报告的问题，不等于整页或整书的最终教学验收结论。
