## 特殊值

- `6456635859` 只是配置界面的“互动游戏”聚合菜单值，不能作为数字模块 type 提交。
- 实际互动游戏必须使用 `56`、`58`、`59`、`63` 或 `64`。
- 定位模块顶层 type 为 `80`；其内容可能再区分位置锚点、大纲或区块目标。不要把内容子类型当作顶层数字模块 type。

## 选型顺序

1. 用户明确指定模块类型时，先用实时 Schema 验证可配置性。
2. 用户只描述点击效果时，选择最窄的实现：网页跳转优先 `81`，书本页面入口优先 `99`，本页导航优先 `80`。
3. 有本地或素材库音视频时使用 `77/78`，不要退化成网页链接。
4. 题目类先读取详情和校验选题再建模块；type 94 先完成讲解查询/生成，资源依赖不完整时不提交半成品模块。
5. 复杂类型无法从零可靠构造时，使用 `editor_copy_digital_module` 复用成熟模块，并明确共享 `model_id`。

## 命名建议

名称应描述学生点击后的结果：

- `打开《岳阳楼记》赏析`
- `播放课文朗读`
- `观看实验演示`
- `跳转本课练习`
- `5 分钟倒计时`

无法得到更具体语义时，省略 `name`，由桥接使用本表对应的数字模块类型名称兜底。
